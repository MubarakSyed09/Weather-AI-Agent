🌦️ Weather AI Agent

An AI-powered weather assistant that provides weather information in a simple, conversational way. Ask about the weather for a location and get useful forecasts and weather-related information.

✨ Features

🌤️ Get current weather information

🌡️ Temperature and weather conditions

💨 Wind and humidity details

🌧️ Rain and precipitation information

📍 Location-based weather queries

🤖 Natural-language interaction with an AI agent

⚡ Fast and easy-to-use interface

🛠️ Tech Stack

Python

AI / LLM

Weather API

REST APIs

Git & GitHub

🚀 Getting Started
1. Clone the repository
git clone https://github.com/MubarakSyed09/weather-ai-agent.git
cd weather-ai-agent

2. Install dependencies
pip install -r requirements.txt

3. Configure environment variables

Create a .env file:

WEATHER_API_KEY=your_weather_api_key
AI_API_KEY=your_ai_api_key

4. Run the application
python main.py

💬 Example
User: What's the weather like in Hyderabad?

AI Agent: Hyderabad is currently 29°C with partly cloudy
conditions. Humidity is 68% with moderate winds.
